04. Ejercicio 1: La Estrategia Humana

Ahora armemos el algoritmo paso a paso (sin programar aún):

  • 1 Preparar el terreno: Vaciar la tabla de destino (TRUNCATE) para no chocar con datos viejos.
  • 2 Catálogo: Tomamos la lista de todos los vehículos (Cursor).
  • 3 El Bucle: Vehículo por vehículo, miramos su historial de 2025.
  • 4 Matemáticas: Contamos (COUNT), sumamos (SUM) y decidimos la clasificación con IF/ELSE.
  • 5 Guardar: Insertamos el resumen en la tabla final.

05. Ejercicio 1: Restricciones Técnicas

¡Atención! La rúbrica tiene reglas estrictas de diseño.

TRUNCATE

No es DML, es DDL. En PL/SQL necesitamos usar EXECUTE IMMEDIATE.

Cursor Austero

Solo trae datos básicos. Nada de COUNT o SUM dentro del Cursor.

SELECT INTO

Las agrupaciones (COUNT, SUM) van en consultas separadas por cada vuelta del loop.

06. Ejercicio 1: El Código (1/2)

-- 1. Declaración y Truncado

DECLARE
    CURSOR c_vehiculos IS 
        SELECT v.cod_vehiculo, t.nombre_tipo_vehiculo, v.modelo, v.valor_arriendo_dia
        FROM VEHICULO_ELECTRICO v JOIN TIPO_VEHICULO t ON t.id_tipo_vehiculo = v.id_tipo_vehiculo
        ORDER BY v.cod_vehiculo;
BEGIN
    EXECUTE IMMEDIATE 'TRUNCATE TABLE RESUMEN_ANUAL_VEHICULO';
    
    OPEN c_vehiculos;
    LOOP
        FETCH c_vehiculos INTO v_cod, v_tipo, v_modelo, v_valor_dia;
        EXIT WHEN c_vehiculos%NOTFOUND;

-- 2. Cálculos obligatorios con SELECT INTO

        SELECT COUNT(*) INTO v_cantidad FROM ARRIENDO_VEHICULO 
        WHERE cod_vehiculo = v_cod AND EXTRACT(YEAR FROM fecha_ini_arriendo) = 2025;

        -- ¡CUIDADO! NVL evita que un SUM nulo rompa el proceso si no hay arriendos
        SELECT NVL(SUM(dias_solicitados), 0) INTO v_total_dias FROM ARRIENDO_VEHICULO 
        WHERE cod_vehiculo = v_cod AND EXTRACT(YEAR FROM fecha_ini_arriendo) = 2025;

07. Ejercicio 1: El Código (2/2)

-- 3. Evitando la División por Cero

        IF v_cantidad = 0 THEN
            v_promedio_dias := 0;
        ELSE
            v_promedio_dias := ROUND(v_total_dias / v_cantidad);
        END IF;
        
        v_ingreso := ROUND(v_valor_dia * v_total_dias);

-- 4. Clasificación e Inserción

        IF v_cantidad >= 6 THEN v_clas := 'Alta';
        ELSIF v_cantidad >= 3 THEN v_clas := 'Media';
        ELSIF v_cantidad >= 1 THEN v_clas := 'Baja';
        ELSE v_clas := 'Sin Demanda';
        END IF;

        INSERT INTO RESUMEN_ANUAL_VEHICULO (...) VALUES (...);
    END LOOP;
    CLOSE c_vehiculos;
    COMMIT;
END;

10. Ejercicio 2: El Truco (La Paramétrica)

¿Por qué Paramétrica?

El porcentaje de aumento (ej: +12% si es Alta) no debe escribirse dentro de los IFs del código fuente.

Debe leerse dinámicamente usando como llave el texto de la clasificación recién calculada.

Buenas Prácticas (100%)

Si mañana el negocio cambia el %, un administrador modifica un dato en la tabla y nuestro código sigue funcionando perfecto sin ser reprogramado.

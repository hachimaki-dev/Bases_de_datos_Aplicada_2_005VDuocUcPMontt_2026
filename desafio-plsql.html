Desafío 20: MercadoShop

10 ejercicios progresivos de PL/SQL

¿Por qué este desafío?

Hasta ahora han dominado SQL puro: consultas, JOINs, funciones de grupo. Pero en el mundo real, las empresas necesitan automatizar procesos: validar stock antes de vender, clasificar clientes, generar reportes dinámicos. Para eso existe PL/SQL.

Este desafío tiene 10 ejercicios progresivos que van desde declarar una variable hasta construir un sistema completo de inventario. No saltes ejercicios — cada uno construye sobre el anterior.

Paso 0: Preparar la Base de Datos

Antes de tocar una sola línea de PL/SQL, necesitas crear las tablas de MercadoShop. Copia el script completo desde el archivo del desafío y ejecútalo en Oracle SQL Developer.

¡No olvides activar DBMS_OUTPUT!

En SQL Developer: Ver → Salida DBMS → clic en el botón verde + para conectar. Sin esto, no verás ningún mensaje de tus bloques PL/SQL.

Verificación: Ejecuta SELECT * FROM productos; — deberías ver 4 filas (Mouse, Teclado, Monitor, Audífonos).

Anatomía de un Bloque PL/SQL

Todo bloque PL/SQL tiene esta estructura. Memorízala antes de empezar:

DECLARE
    -- Aquí declaras tus variables
    v_nombre VARCHAR2(100);
    v_precio NUMBER;
BEGIN
    -- Aquí va tu lógica (SELECT INTO, IF, bucles, etc.)
    DBMS_OUTPUT.PUT_LINE('Hola mundo');
END;
/

DECLARE

Declaras variables con nombre, tipo y opcionalmente valor inicial.

BEGIN ... END;

Tu código ejecutable. Aquí van los SELECT INTO, IF, LOOP, etc.

La barra /

El / al final le dice a Oracle "ejecuta todo el bloque". ¡No lo olvides!

Los 10 Ejercicios

1

Mi primer bloque — Saludo personalizado

🟢 BÁSICO

Declara dos variables y usa DBMS_OUTPUT.PUT_LINE para imprimir un saludo.

💡 Tips para avanzar

• Las variables de texto se declaran con VARCHAR2(tamaño).

• Para asignar un valor usas := (dos puntos + igual).

• Para concatenar textos usas || igual que en SQL.

2

Leer desde la BD — SELECT INTO

🟢 BÁSICO

Lee el nombre y precio del producto con id_producto = 10.

💡 Tips para avanzar

• La sintaxis es: SELECT col1, col2 INTO v_var1, v_var2 FROM tabla WHERE ...

• El WHERE debe devolver exactamente 1 fila. Si devuelve 0 o más de 1, Oracle lanza un error.

• Declara tus variables con el mismo tipo de dato que las columnas de la tabla.

3

Precio con IVA

🟢 BÁSICO

Lee el precio del producto 30 y calcula el precio con 19% de IVA.

💡 Tips para avanzar

• Primero haces el SELECT INTO para obtener el precio.

• Luego creas otra variable para el resultado: v_con_iva := v_precio * 1.19;

• Sumar un 19% es lo mismo que multiplicar por 1.19.

4

Alerta de stock

🟡 INTERMEDIO

Lee el stock del producto 20 y clasifícalo con IF/ELSIF/ELSE.

💡 Tips para avanzar

• ¡El orden de los IF importa! Evalúa primero el caso más restrictivo (= 0) y avanza hacia el menos restrictivo.

• La estructura es: IF condición THEN ... ELSIF condición THEN ... ELSE ... END IF;

• Puedes guardar el estado en una variable de texto: v_estado VARCHAR2(30);

5

Clasificar tipo de cliente

🟡 INTERMEDIO

Lee el tipo de cliente del cliente 1 y asigna un % de descuento.

💡 Tips para avanzar

• Compara textos con =, no con LIKE: IF v_tipo = 'VIP' THEN ...

• Los textos en Oracle son case-sensitive: 'VIP' ≠ 'vip'.

• Declara una variable v_descuento NUMBER; para guardar el porcentaje.

6

Tabla de descuentos con FOR

🟡 INTERMEDIO

Usa un bucle FOR para mostrar 5 descuentos escalonados del Monitor.

💡 Tips para avanzar

• La sintaxis del FOR es: FOR i IN 1..5 LOOP ... END LOOP;

• Si i va de 1 a 5, el porcentaje de descuento es i * 10 (10%, 20%, ..., 50%).

• Para calcular el precio con descuento: v_precio * (1 - i * 10 / 100)

• Haz el SELECT INTO antes del bucle (solo necesitas leer el precio una vez).

7

Contador con LOOP

🔴 AVANZADO

Suma del 1 al 10 usando LOOP (sin FOR).

💡 Tips para avanzar

• Necesitas dos variables: un contador (v_i) y un acumulador (v_suma).

• Dentro del LOOP: primero sumas, luego incrementas el contador.

• La salida es: EXIT WHEN v_i > 10; — pero piensa bien dónde ponerla.

8

Revisar todos los productos

🔴 AVANZADO

Itera los 4 productos, lee cada uno con SELECT INTO y clasifica su stock.

💡 Tips para avanzar

• Los IDs son 10, 20, 30, 40. Si iteras FOR i IN 1..4, el ID es i * 10.

• Puedes poner un SELECT INTO dentro de un bucle sin problema.

• Reutiliza la lógica del IF que ya hiciste en el ejercicio 4.

9

Bloques anidados — Validar pedido

🔴 AVANZADO

Un bloque padre lee el pedido 100 y un bloque hijo consulta los datos del cliente.

💡 Tips para avanzar

• Un bloque hijo se escribe literalmente como otro DECLARE ... BEGIN ... END; dentro del BEGIN del padre.

• El hijo sí puede acceder a las variables del padre (por ejemplo, v_id_cliente).

• Lee primero el pedido (obtendrás el id_cliente), luego en el hijo usa ese ID para buscar el cliente.

• Para saber si es VIP: IF v_tipo = 'VIP' THEN v_es_vip := 'Sí'; ...

10

DESAFÍO INTEGRADOR — Resumen de inventario

🔴🔴 JEFE FINAL

Combina TODO lo aprendido: SELECT INTO + IF + FOR + bloques anidados + acumuladores.

💡 Estrategia de ataque (lee esto con calma)

Paso 1: Declara el acumulador v_valor_total NUMBER := 0; en el bloque padre.

Paso 2: Arma el FOR de 1 a 4. Dentro, calcula el ID con i * 10.

Paso 3: Dentro del FOR, haz el SELECT INTO para leer nombre, precio y stock.

Paso 4: Calcula el valor en bodega: v_valor_bod := v_precio * v_stock;

Paso 5: Acumula: v_valor_total := v_valor_total + v_valor_bod;

Paso 6: Dentro del FOR, abre un bloque hijo con el IF para clasificar el stock.

Paso 7: Después del END LOOP, imprime el total.

Si te trabas: Primero haz que funcione SIN el bloque hijo (solo el FOR con SELECT INTO y el acumulador). Cuando eso funcione, agrega el IF.

Clínica de Errores PL/SQL

Si Oracle te lanza un error rojo, búscalo aquí antes de levantar la mano:

❌ ORA-01403: no data found

Causa: Tu SELECT INTO devuelve 0 filas. El WHERE no encontró coincidencias.

Fix: Revisa el valor que pusiste en el WHERE. ¿Existe ese ID en la tabla? Haz un SELECT normal primero para verificar.

❌ ORA-01422: exact fetch returns more than requested number of rows

Causa: Tu SELECT INTO devuelve más de 1 fila. PL/SQL no sabe en cuál guardar el dato.

Fix: Agrega o ajusta tu WHERE para que filtre exactamente 1 registro (usa la PK).

❌ PLS-00201: identifier must be declared

Causa: Estás usando una variable que no declaraste en el DECLARE.

Fix: Revisa que el nombre de la variable en el BEGIN sea idéntico al del DECLARE (sin typos).

❌ No veo ningún mensaje en pantalla

Causa: No activaste la salida DBMS_OUTPUT.

Fix: En SQL Developer: Ver → Salida DBMS → botón verde +. Luego vuelve a ejecutar tu bloque.

❌ PLS-00103: Encountered the symbol "END" when expecting...

Causa: Te falta un punto y coma ; en alguna línea anterior al END.

Fix: Revisa que TODAS las líneas dentro del BEGIN terminen con ;. Incluido el END IF; y el END LOOP;.
